# Nextdrop

A modern dropshipping website designed to help users discover winning products, connect with suppliers, and grow their online business.

## Features

- Responsive design
- Modern user interface
- Product showcase section
- Hero banner
- Search functionality
- Supplier information
- FAQ section
- Contact page
- Login and registration pages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/dropsphere.git
```

2. Open the project folder:

```bash
cd dropsphere
```

3. Open `index.html` in your browser.
